# Common typos

A dataset contain common typos. Used in the `typos` argument of
[`fix_typos()`](fix_typos.md) and
[`extractMemberName()`](extractMemberName.md).

## Usage

``` r
typos
```

## Format

A data frame with 480 rows and 2 variables:

- `typos`:

  character COLUMN_DESCRIPTION

- `correct`:

  character COLUMN_DESCRIPTION
