# Text of the Congressional Record from 3/1/2007, parsed by speaker using the congressionalrecord package

Text of the Congressional Record from 3/1/2007, scraped and parsed using
methods described
[here](https://github.com/judgelord/congressionalrecord).

## Usage

``` r
cr2007_03_01
```

## Format

A data frame with 154 rows and 5 variables:

- `date`:

  date Congressional Record date

- `congress`:

  double session of Congress

- `speaker`:

  character speaker stated in the record

- `header`:

  character header under which this text of the record appeared

- `url`:

  character URL to the record html version of the page
